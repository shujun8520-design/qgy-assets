# qgy-assets

《人妻公寓》运行时成人 CG 资源仓库。

## cg4（夏乔「借种」结局专属 CG）

- 在 cg3 的普通／怀孕双图库基础上，新增 14 张夏乔「借种」结局专属 WebP。
- 目录：`cg1/borrow-seed-ending/`；其中 7 张为剧情／家庭节点画面，7 张为连续成人剧情画面。
- 这些图片由游戏的结构化借种状态机独占，不并入普通或孕肚随机图库，也不改变 cg3 的 1448 个既有条目。
- 文件名、分类与 SHA-256 见 `cg1/borrow-seed-ending/manifest.json`。

## cg3（普通／怀孕双图库，统一五阶段）

- 普通成人 CG：1070 张；怀孕成人 CG：378 张；合计 1448 张。
- 两套图库均使用同一套五阶段与动作语义，运行时按 `variant` 严格分线，不跨图库回退。

### 普通 CG 五阶段

- 普通接触：62 张。
- 深度前戏：361 张。
- 进行中（仅阴茎或道具进入前后穴）：426 张。
- 事后（动作结束且精液可见）：35 张。

### 怀孕 CG 五阶段

- 亲密开场（无男方接触）：41 张。
- 普通接触：32 张。
- 深度前戏：110 张。

- 事后（动作结束且精液可见）：59 张。

- 格式：WebP；1448 个公开条目均有唯一 ID、path 与文件 SHA-256。
- 运行时清单：`cg1/manifest.json`。
- 公开图片路径以 manifest 为准；普通 CG 保持既有 CDN 路径兼容，怀孕 CG 位于 `assets/<door>/pregnancy/<stage>/`。
